========================================================
一、需要下载安装的软件清单
========================================================

1. JDK 17（Java开发环境）
2. MySQL 8.0（数据库）
3. Redis（缓存服务）
4. Node.js 18+（前端运行环境）
5. IntelliJ IDEA（后端开发工具）
6. 微信开发者工具（小程序开发工具）


========================================================
二、安装 JDK 17
========================================================

下载地址：https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html
备用地址：https://adoptium.net/zh-CN/temurin/releases/?version=17

安装步骤：
1. 下载 Windows x64 Installer（.msi 或 .exe 文件）
2. 双击安装，全部默认下一步即可
3. 安装完成后配置环境变量：
   - 右键"此电脑" → 属性 → 高级系统设置 → 环境变量
   - 新建系统变量：变量名 JAVA_HOME，变量值填 JDK 安装路径（如 C:\Program Files\Java\jdk-17）
   - 编辑 Path 变量，新增一行：%JAVA_HOME%\bin
4. 验证安装：打开命令提示符（cmd），输入 java -version，应显示 java version "17.x.x"


========================================================
三、安装 MySQL 8.0
========================================================

下载地址：https://dev.mysql.com/downloads/installer/
选择 Windows (x86, 32-bit), MSI Installer（完整版）

安装步骤：
1. 双击安装包，选择 "Developer Default" 或 "Server only"
2. 一路下一步，到配置页面时注意：
   - 端口保持默认 3306
   - 设置 root 密码为：root（必须与项目配置一致）
   - 勾选"Configure MySQL Server as a Windows Service"
3. 完成安装

验证安装：
- 打开 cmd，输入：mysql -u root -p
- 输入密码 root，能进入 MySQL 命令行则成功

备用工具 - Navicat（数据库可视化管理）：
下载地址：https://www.navicat.com.cn/download/navicat-for-mysql
（也可使用免费的 DBeaver：https://dbeaver.io/download/）


========================================================
四、安装 Redis
========================================================

Windows 版下载地址：https://github.com/tporadowski/redis/releases
下载 Redis-x64-xxx.msi 安装包

安装步骤：
1. 双击 .msi 安装包
2. 全部默认下一步
3. 勾选"Add the Redis installation folder to the PATH environment variable"
4. 端口保持默认 6379
5. 安装完成后 Redis 会自动以 Windows 服务方式运行

验证安装：
- 打开 cmd，输入：redis-cli ping
- 如果返回 PONG，说明 Redis 正常运行

注意：如果不安装 Redis，系统也能运行，只是缓存功能不可用，不影响核心业务。


========================================================
五、安装 Node.js
========================================================

下载地址：https://nodejs.org/zh-cn
选择 LTS（长期支持版），下载 Windows Installer (.msi)

安装步骤：
1. 双击安装包，全部默认下一步
2. 安装完成后验证：
   - 打开 cmd，输入：node -v（应显示 v18.x.x 或更高）
   - 输入：npm -v（应显示版本号）

设置国内镜像加速（推荐）：
打开 cmd，执行：
npm config set registry https://registry.npmmirror.com

========================================================
八、导入并初始化数据库
========================================================

方法一：使用命令行
1. 打开 cmd
2. 执行以下命令：
   mysql -u root -p < "项目路径\backend\src\main\resources\db\init.sql"
3. 输入密码 root

方法二：使用 Navicat / DBeaver
1. 打开 Navicat，连接 MySQL（主机:localhost，端口:3306，用户名:root，密码:root）
2. 右键连接 → 新建数据库，名称输入：research_db，字符集选 utf8mb4
3. 双击打开 research_db 数据库
4. 右键 → 运行 SQL 文件 → 选择项目中的 backend\src\main\resources\db\init.sql
5. 点击"开始"执行

执行完成后应该能看到以下数据表：
- sys_college（学院信息表）
- sys_user（用户信息表）
- research_project（科研项目表）
- project_member（项目成员表）
- project_budget（经费预算表）
- project_settlement（经费结算表）
- research_paper（论文专著表）
- research_patent（专利表）
- approval_record（审批记录表）
- task_book（任务书表）
- sys_notice（通知消息表）
- operation_log（操作日志表）


========================================================
九、IDEA 导入并启动后端项目
========================================================

步骤一：导入项目
1. 打开 IDEA
2. 选择 File → Open
3. 选择项目中的 backend 文件夹（注意是 backend 目录，不是整个项目根目录）
4. 选择 "Open as Project"
5. 等待 IDEA 自动下载 Maven 依赖（右下角进度条，首次可能需要 5-10 分钟）

步骤二：配置 JDK
1. File → Project Structure → Project
2. SDK 选择 JDK 17
3. Language Level 选择 17
4. 点击 OK

步骤三：检查 Maven 设置
1. File → Settings → Build → Build Tools → Maven
2. 确认 Maven home directory 指向已安装的 Maven 或 IDEA 自带的 Maven
3. 如果未安装 Maven，IDEA 自带的 Bundled Maven 就可以使用

步骤四：修改数据库配置（如果你的密码不是 root）
1. 打开 backend/src/main/resources/application.yml
2. 修改以下配置（按你的实际情况）：
   spring.datasource.username: root       ← 你的 MySQL 用户名
   spring.datasource.password: root       ← 你的 MySQL 密码
   spring.datasource.url 中的 3306        ← 你的 MySQL 端口号

步骤五：启动后端
1. 在 IDEA 左侧找到 src/main/java/com/research/ResearchApplication.java
2. 右键该文件 → Run 'ResearchApplication'
3. 等待控制台输出：Started ResearchApplication in x.xxx seconds
4. 看到此信息说明后端启动成功，运行在 http://localhost:8088

常见报错：
- "Port 8088 already in use" → 有其他程序占用了8088端口，关掉后重试
- "Communications link failure" → MySQL 未启动，请先启动 MySQL 服务
- "Access denied for user 'root'" → 密码错误，检查 application.yml 中的密码


========================================================
十、启动 PC 前端项目
========================================================

步骤一：安装依赖
1. 打开 cmd 或 PowerShell
2. 进入前端目录：cd "项目路径\frontend-pc"
3. 执行：npm install
4. 等待安装完成（首次可能需要 2-5 分钟）

步骤二：启动开发服务器
1. 在同一目录下执行：npm run dev
2. 看到输出：VITE ready in xxx ms → Local: http://localhost:5173/
3. 打开浏览器访问：http://localhost:5173/

注意：
- 必须先启动后端（第九步），再打开前端页面
- 如果 5173 端口被占用，Vite 会自动使用 5174 等端口
- 推荐使用 Chrome 或 Edge 浏览器


========================================================
十一、启动微信小程序端
========================================================

1. 打开微信开发者工具
2. 选择"导入项目"
3. 项目目录选择：项目路径\miniprogram
4. AppID 可以使用测试号，或者点击"使用测试号"
5. 点击"导入"
6. 等待编译完成，即可在模拟器中看到小程序界面

注意：
- 小程序连接的后端地址是 http://localhost:8088（在 miniprogram/app.js 中配置）
- 需要先启动后端服务
- 如果真机调试，需在微信开发者工具中开启"不校验合法域名"选项：
  详情 → 本地设置 → 勾选"不校验合法域名、web-view（业务域名）..."

========================================================
十三、常见问题解答
========================================================

Q1：后端启动报错 "Cannot determine embedded database driver class"
A：MySQL 未启动或连接信息有误。检查 MySQL 是否运行中，application.yml 中账号密码是否正确。

Q2：前端页面显示 Vite 默认欢迎页
A：按 Ctrl+Shift+R 强制刷新浏览器缓存，或者检查是否有其他 Vite 项目占用了 5173 端口。

Q3：前端页面白屏
A：打开浏览器 F12 控制台查看报错。通常是后端未启动导致接口请求失败。

Q4：小程序显示"网络异常"
A：确认后端已启动（http://localhost:8088），且小程序 app.js 中 baseUrl 地址正确。

Q5：Redis 未安装怎么办？
A：可以不安装 Redis。项目在 Redis 连接失败时会自动降级，核心功能不受影响，只是统计数据缓存不可用。

Q6：如何修改后端端口？
A：编辑 backend/src/main/resources/application.yml，修改 server.port 的值。同时需修改：
   - frontend-pc/src/api/request.js 中的 baseURL
   - miniprogram/app.js 中的 baseUrl

Q7：数据库表不存在报错
A：确认已执行 init.sql 初始化脚本（见第八步）。


========================================================
        启动顺序总结（务必按此顺序）
========================================================

1. 启动 MySQL 服务
2. 启动 Redis 服务（可选）
3. IDEA 启动后端 → 确认控制台显示 Started 成功
4. 命令行启动前端 → npm run dev → 浏览器访问 5173
5. 微信开发者工具打开小程序 → 导入 miniprogram 目录

三端地址：
- 后端 API：http://localhost:8088
- PC 前端：http://localhost:5173
- 小程序：微信开发者工具中运行
