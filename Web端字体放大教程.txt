======================================
  科研管理系统 Web端 字体放大教程
======================================

只需修改1个文件，所有页面自动生效。

--------------------------------------
方法：已打包部署的环境
--------------------------------------

步骤1：找到前端部署目录
  打开你部署前端的文件夹，找到 dist 目录

步骤2：找到 index.html 文件
  在部署目录根目录下，打开 index.html（用记事本即可）

步骤3：在 <head> 标签内添加以下代码
  找到 <head> 这一行，在它的下一行粘贴以下内容：

  <style>
    /* 全局字体放大 - 可自行调整数值 */
    body { font-size: 18px !important; }
    .el-table { --el-table-font-size: 17px !important; }
    .el-form-item__label { font-size: 17px !important; }
    .el-input__inner, .el-textarea__inner { font-size: 17px !important; }
    .el-menu-item, .el-sub-menu__title { font-size: 16px !important; }
    .el-button { font-size: 16px !important; }
    .el-dialog__title { font-size: 20px !important; }
    .el-pagination { font-size: 16px !important; }
    .el-tag { font-size: 15px !important; }
  </style>

步骤4：保存文件，刷新浏览器即可看到效果
  按 Ctrl+F5 强制刷新页面

--------------------------------------
【字体大小参考】
--------------------------------------

  想要的效果             body字体值      建议
  稍微大一点            17px              小幅放大
  明显大一点（推荐）   18px         适中放大
  很大                20px         大幅放大，可能影响布局

  提示：上面给出的代码默认是 18px（明显大一点），
  如果觉得还不够大，把所有数值再各加 2 即可。

--------------------------------------
【注意事项】
--------------------------------------
1. 方法一最简单，改完刷新就能看到效果
2. 方法一修改后，如果以后重新部署前端代码，需要重新加上这段代码
3. 如果用了方法二（源码修改+重新打包），以后每次部署都会自动带上
4. 只影响 Web 管理后台，不影响微信小程序端
5. 后端不需要任何修改
